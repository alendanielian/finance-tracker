# Материалы Google Play для Finance Tracker

## Готовые файлы

| Назначение | Файл | Технические свойства |
| --- | --- | --- |
| Иконка страницы приложения | `app_icon_512.png` | 512×512, RGBA PNG, менее 1024 КБ |
| Feature Graphic | `feature_graphic_1024x500.png` | 1024×500, RGB PNG без alpha |
| Скриншоты телефона | `screenshots/01_...05_..._1080x1920.png` | 1080×1920, RGB PNG, 9:16 |
| Обзор серии | `screenshots/contact_sheet.jpg` | Только для внутренней проверки |

Финальные скриншоты, которые следует загружать в Play Console:

1. `01_home_1080x1920.png` — обзор баланса;
2. `02_add_expense_1080x1920.png` — добавление расхода;
3. `03_budget_1080x1920.png` — месячный лимит;
4. `04_analytics_1080x1920.png` — диаграмма и динамика баланса;
5. `05_privacy_1080x1920.png` — настройки конфиденциальности.

Папка `screenshots/raw/` содержит реальные кадры Flutter 1080×2400 до
маркетинговой компоновки. В них используются только вымышленные демонстрационные
операции из временной Hive-базы.

## Воспроизводимость

1. `tool/prepare_store_assets.py` нормализует исходный знак, создаёт иконки и Feature Graphic.
2. `flutter pub run flutter_launcher_icons` обновляет ресурсы Android.
3. `flutter test tool/store_screenshots_test.dart --no-pub` снимает реальные Flutter-экраны.
4. `tool/compose_store_screenshots.py` создаёт финальную серию 1080×1920.

Для Python-скриптов нужен Pillow. В этой рабочей среде он уже доступен в
комплектном Python Codex.

## Исходные изображения

Знак приложения был создан по запросу: минималистичная иконка оффлайн-трекера
финансов, кошелёк или карточка с тремя растущими столбцами, без текста и знаков
валют, на прозрачном фоне, с белым, мятным и тёплым жёлтым цветами и безопасной
областью для Android adaptive icon.

Фон Feature Graphic был создан по запросу: широкий премиальный абстрактный фон
в тёмно-бирюзовой палитре; слева мягкий график роста, справа круговая диаграмма
и карточки категорий, свободная центральная область, без текста, логотипов,
цен и рекламных заявлений.

Необработанный foreground сохранён в `assets/source/app_icon_foreground_raw.png`,
фон баннера — в `feature_graphic_background.png`. Текст и точные размеры
накладываются детерминированно скриптами, поэтому материалы можно пересобрать.
